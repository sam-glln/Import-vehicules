Espace propriétaire

Connectez-vous avec votre clé d'accès GitHub pour gérer l'inventaire. Les modifications sont publiées directement sur le site.

Comment obtenir ma clé d'accès ?
  1. Connectez-vous sur github.com, puis ouvrez cette page de création de clé (Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token).
  2. Token name : par exemple « Site — espace propriétaire ». Expiration : choisissez une durée (par exemple 1 an), il faudra la renouveler ensuite.
  3. Repository access : « Only select repositories », puis sélectionnez le dépôt du site uniquement.
  4. Permissions → Repository permissions → Contents : choisissez « Read and write ».
  5. Cliquez sur Generate token, copiez la clé (elle commence par github_pat_) et collez-la ci-dessus. Conservez-la dans votre gestionnaire de mots de passe : GitHub ne l'affiche qu'une fois.
